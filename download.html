Mochi & Snow are hand-drawn lop-eared bunnies that walk, hop, blink and nap on top of your windows. The free edition is a single portable file. No installer, no account, no network access.

What the free edition includes

Everything you need to decide whether they belong on your desktop.

8 actions

Turn, look around, shake, take a step, run, hop, spin and fall asleep.

Two characters

Mochi (caramel) and Snow (white with a pink bow) — each with natural blinking and idle behaviour.

Drag & drop

Pick them up with the mouse, move them around, and they'll walk back to a spot you choose.

Zero footprint

No installer, no registry writes, no telemetry, no network calls. One file, delete it and you're done.

Install in three steps

  1. Download the .exe with the button above and put it anywhere you like — Desktop is fine.
  2. Double-click it. Windows SmartScreen may warn because the file is not code-signed. Choose "More info" → "Run anyway".
  3. They appear. Right-click the tray icon to pause, or run 停止桌宠.bat to exit. Deleting the .exe removes everything.
Because the file is unsigned, some antivirus tools flag newly published portable apps. If you'd rather not run a binary, the browser version shows the same characters with no download at all.
