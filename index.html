Not there after an hour? Check your spam folder (the message comes from fuxs9056@agent.qq.com), then write to that same address and we will send it by hand. The links never expire, so you can also re-download them later on a new computer.

Windows says "Windows protected your PC". Is this a virus?

No. That blue box is SmartScreen, and it appears for any new app that hasn't paid Microsoft for a code-signing certificate — which is most indie software. Click More info, then Run anyway. The app makes no network connections at all, so you can verify that yourself with any firewall tool.

My antivirus flagged it. Should I worry?

Some antivirus engines flag small apps that move windows around, because that behaviour overlaps with what certain malware does. Add the folder to your antivirus allow-list. The exact steps for Microsoft Defender, 360 and Huorong are in the README inside the download.

Does it need an internet connection?

No. It works completely offline and never connects to anything. There is no account, no licence server and no telemetry.

Does it install anything?

No. It's portable. Unzip it anywhere and double-click the .exe. No installer, no registry entries, no admin rights needed. To remove it, delete the folder.

Will it slow my computer down?

It idles at a very low CPU cost and pauses itself while you're playing games or running a full-screen app. It also stops your PC from sleeping automatically, which is normally what you want from a desktop pet.

Can I run it on more than one computer?

Yes — use it on all the computers you personally own. Please don't redistribute it.

What if I don't like it?

Email us within 7 days of purchase and we'll refund you in full, no questions asked. See our Refund Policy.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit. It also runs on Windows 8.1 and 7, though we only test on 10 and 11.
