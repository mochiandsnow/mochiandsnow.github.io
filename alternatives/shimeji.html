What Shimeji does better

If none of these matter to you, skip ahead. They are real reasons people pick it.

  • Free and open source, with a large back catalogue of community sprite packs
  • Very light on disk — around 27 MB
  • Deeply configurable through XML files if you want to build your own character
  • Several characters can spawn at once, and they will throw your windows around

Where it asks something of you

  • You need Java installed before anything runs, which is where a lot of people stop
  • Interaction is limited to crawling, hanging on window edges and being dragged or thrown
  • No dialogue, no 3D, no dance — the animation set is a fixed sprite sheet
  • Throwing windows is a default behaviour and will interrupt your work until you turn it off
  • Quality varies between forks, because the original is discontinued
  • Most sprite packs are fan art of existing IP, which is a licensing grey area

What Mochi & Snow does differently

  • Installs as an app — no Java runtime to install, no XML to edit
  • It does not throw your windows, so it never interrupts what you are doing
  • Two characters that interact with each other — they nuzzle, hug and share a moment
  • Original characters, so you are not shipping someone else's IP
  • One-time purchase with a 7-day refund, and a free in-browser try first

Questions this comparison raises

Which desktop pet app should I start with?

Start from what you already have. If you own Live2D models, Live2DViewerEX will use them. If you want a licensed 3D anime character, Desktop Mate sells those as DLC. If you want free and open source and will build your own sprite pack, Shimeji is hard to beat. Mochi & Snow is for the case where you want two finished original characters and pay for them once.

Is Mochi & Snow free?

The browser demo is free and needs no signup, so you can watch the bunnies move before paying. The Windows app is a one-time $5.99. There is no subscription and no character DLC.

Does Mochi & Snow cost more than the alternatives?

Compared with Live2DViewerEX at $4.99 it costs about a dollar more, and unlike that app it includes the characters. Compared with Desktop Mate the app is not free, but you are not buying characters at about ¥76 each afterwards. Compared with Shimeji it costs money where Shimeji is free — Shimeji asks for a Java install and XML work instead.

Can I run Mochi & Snow on macOS or Linux?

Mochi & Snow is a Windows 10 and 11 app. Desktop Mate and Live2DViewerEX ship macOS and Linux builds, and Shimeji has macOS and Linux forks. If you are not on Windows, one of those is the better answer.

Do these apps need an internet connection?

The Mochi & Snow desktop app makes no network calls at all. Desktop Mate and Live2DViewerEX both use a store and a workshop for content, so they need a connection to fetch new characters or models.
